# Node 24 下限提升到 24.11

[English](guide.md) | 中文

## 变更

本仓库现在使用 [Vite+](https://viteplus.dev/) 运行测试、静态检查与构建，其捆绑工具要求 Node `^22.18.0 || ^24.11.0 || >=26.0.0`。因此根 `package.json` 的 `engines` 范围由 `^22.19.0 || >=24.0.0` 收窄为 `^22.19.0 || ^24.11.0 || >=26.0.0`，CI 兼容性矩阵也把仍然搭载 v1 internal loader 的 Node 24.9 任务替换为 24.11。

已发布的 `@deepseek-ai/dsh-*` 包没有声明 `engines`，也不分发工具链的一部分，因此安装与运行不受影响。该下限约束的是贡献者、CI，以及从源码构建本仓库的人。

## 迁移

1. 将任何需要构建或测试本仓库的主机升级到 Node 22.19+、24.11+ 或 26+。Node 24.10 及更早版本仍可运行已发布的包，但无法再运行本仓库的工具链。

```sh
node --version
pnpm install
```

2. 若主机固定了旧下限，请替换它。只安装已发布包的主机无需改动。

```sh
# before
"engines": { "node": "^22.19.0 || >=24.0.0" }
# after
"engines": { "node": "^22.19.0 || ^24.11.0 || >=26.0.0" }
```

3. 无法升级的主机请停留在本仓库的上一个版本；其工具链早于该下限。
